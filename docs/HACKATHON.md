## Project description

READIT helps developers understand an application beyond its README. A coding-agent skill discovers user goals and traces their implementation, then produces an interactive map of UML use cases and playable sequence diagrams. Every source-backed claim points to code; uncertain steps are explicitly marked. The result is a portable, offline exploration experience for onboarding and reviewing AI-generated code.

## Three-minute demo plan

| Time | Show | Explain |
|---|---|---|
| 0:00–0:25 | A repository and its README | Setup documentation does not explain every behavior; AI-generated code can outpace shared understanding. |
| 0:25–0:50 | Invoke `$readit`; show a generated model | The agent investigates source and records scope, goals, flows, and evidence. Show recorded output if a live analysis takes too long. |
| 0:50–1:15 | Use case map; click Place an order | Start with the user's goal, then follow its implementation. |
| 1:15–1:50 | Step through successful checkout; open source | See reservation, payment, and persistence with exact references. Source-backed is an inspectable claim, not a correctness guarantee. |
| 1:50–2:15 | Select Payment declined | The failure path releases stock. Understanding includes compensation, not just the happy path. |
| 2:15–2:40 | Inferred caller step; add review note | Assumptions stay visible, and the developer can request clarification. |
| 2:40–3:00 | Offline HTML and PlantUML download | Open source, local tooling, portable results, and an installable skill. |

The Little Shop example is intentionally small and uses a payment stub. Include a real repository analysis in your video if you can review its accuracy before recording. Do not imply the demo fixture is production software.

## Submission checklist

- Push the repository publicly; retain the visible Git history.
- Confirm README quick start on another machine.
- Keep LICENSE and third-party notices.
- Fill in exact AI model/tool names from your actual sessions in the disclosure.
- Record the demo video; no video is generated by this source package.
- Include the repository link, problem/solution, AI explanation, and video in the organizer's submission form.
- State prototype limits and describe future features as future work.
